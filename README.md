## 🚀 Quick Start

### Prerequisites
- **Node.js v20+** ([Download](https://nodejs.org/))
- **npm** package manager
- **Active WhatsApp Account**
- **Internet Connection**

### One-Command Setup

```bash
git clone https://github.com/arslantech/Arslan-MD-Ultra-V5.git
cd Arslan-MD-Ultra-V5
npm install
npm start
